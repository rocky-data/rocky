Rocky is a single static binary. There is no separate runtime to install, and no package manager to configure. Pick your platform below.

<Tabs syncKey="os">
<TabItem label="macOS / Linux">

```bash
curl -fsSL https://raw.githubusercontent.com/rocky-data/rocky/main/engine/install.sh | bash
```

The script installs to `~/.local/bin/rocky` and verifies the checksums. Make sure `~/.local/bin` is on your `PATH`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

</TabItem>
<TabItem label="Windows">

```powershell
irm https://raw.githubusercontent.com/rocky-data/rocky/main/engine/install.ps1 | iex
```

</TabItem>
</Tabs>

## Published releases and source builds

The installer downloads a published engine release. Merged changes on `main` can arrive before the next release.
Check `rocky --version` and the [release notes](https://github.com/rocky-data/rocky/releases) before relying on a new capability.
For a source build, also record `git rev-parse HEAD`. Different source revisions can print the same version before a release bump.

## Options

The install script takes these settings, both optional.

Install to a custom directory:

```bash
curl -fsSL https://raw.githubusercontent.com/rocky-data/rocky/main/engine/install.sh \
  | ROCKY_INSTALL_DIR=/usr/local/bin bash
```

Pin a specific version:

```bash
curl -fsSL https://raw.githubusercontent.com/rocky-data/rocky/main/engine/install.sh | bash -s -- <version>
```

## Pre-built binaries

Prefer to download the archive yourself? Take it from the [releases page](https://github.com/rocky-data/rocky/releases):

| Platform | Archive |
|---|---|
| macOS (Apple Silicon) | `rocky-aarch64-apple-darwin.tar.gz` |
| macOS (Intel) | `rocky-x86_64-apple-darwin.tar.gz` |
| Linux x86_64 | `rocky-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64 | `rocky-aarch64-unknown-linux-gnu.tar.gz` |
| Windows x86_64 | `rocky-x86_64-pc-windows-msvc.zip` |

## Container image

Every engine release also publishes `ghcr.io/rocky-data/rocky`, for `linux/amd64` and `linux/arm64`. The image is the CLI, so any command runs the same way:

```bash
docker run --rm -v "$PWD:/data" ghcr.io/rocky-data/rocky:latest --version
```

[Run the Container Image](/guides/run-the-image/) covers the server, the volume, the token, the health probe, and upgrades.

## Build from source

Requires Rust 1.88+ (edition 2024).

```bash
git clone https://github.com/rocky-data/rocky.git
cd rocky/engine
cargo build --release
# binary at target/release/rocky
```

## Verify

Confirm the binary is on your `PATH` and prints a version:

```bash
rocky --version
```
