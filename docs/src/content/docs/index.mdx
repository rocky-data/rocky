## What Rocky is

Rocky is a typed SQL compiler and run engine. You write SQL and TOML. Rocky compiles the project and reports the static problems it can find before anything runs. Then it sends generated SQL to your warehouse.

A clean compile does not prove general SQL validity or correct result values. See [what Rocky checks](/getting-started/introduction/).

## Install and run

```bash
curl -fsSL https://raw.githubusercontent.com/rocky-data/rocky/main/engine/install.sh | bash
rocky playground my-first-project
cd my-first-project
rocky compile            # type-check
rocky run                # materialize the DAG on local DuckDB
```

You need no credentials. Other platforms: [Installation](/getting-started/installation/). The full walk-through is the [Quickstart](/getting-started/quickstart/).

## What you get

| Need | Command | Page |
|---|---|---|
| Typed compile errors with fixes | `rocky compile` | [Compiler](/concepts/compiler/) |
| Column-level lineage for PR review | `rocky lineage-diff main` | [Introduction](/getting-started/introduction/) |
| Isolated branches and run replay | `rocky branch create`, `rocky replay <run_id>` | [Shadow mode](/concepts/shadow-mode/) |
| Per-model cost, as an estimate and not a bill | `rocky cost` | [Introduction](/getting-started/introduction/) |
| A way out, with no lock-in | `rocky emit-sql` | [No lock-in](/guides/no-lock-in/) |

## Who it is for

Rocky is built first for data platform engineers who run production-critical, multi-tenant pipelines on Databricks. That is where it has the most production mileage.

Snowflake and BigQuery adapters are Beta. See the [Roadmap](/getting-started/roadmap/).
