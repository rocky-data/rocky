The playground ships **{pocCounts.total} self-contained POCs** across {pocCounts.categoryCount} categories. Each is a small project with its own `rocky.toml`, a `models/` directory and one `run.sh` that shows one capability end to end. Most run on local DuckDB with no credentials.

The [Quickstart](/getting-started/quickstart/) and [Playground](/guides/playground/) walkthroughs teach the workflow. The POCs show one capability each, in isolation.

## Run one

```bash
git clone https://github.com/rocky-data/rocky.git
cd rocky/examples/playground

# Run any POC end-to-end (DuckDB, no credentials)
./pocs/02-performance/01-incremental-watermark/run.sh
```
